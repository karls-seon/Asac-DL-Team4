# 원룸3D — 매물 사진 기반 3D 공간 재구성

매물 사진 3~5장으로 방을 3D 복원하고, 옵션 가구를 지운 뒤 내 가구를 배치해보는 뷰어.

ASAC 빅데이터 분석 11기 · 딥러닝 4조 (5인) · 2026.07

## 배경

- 매물 사진은 광각이라 공간감이 왜곡됨. 장수도 3~5장뿐
- 평면도 기반 인테리어 서비스는 평면도가 없으면 못 씀
- VR 홈투어는 360도 카메라로 재촬영 필요

→ 이미 올라와 있는 사진만으로 되는지 확인해본 프로젝트

## 파이프라인

```
사진 3~5장
  → DUSt3R 3D 복원 (Point Cloud)
  → YOLO11s + SAM2 가구 세그멘테이션
  → 주변 Point Cloud 색상으로 가상 벽 생성 (배경 보완)
  → TripoSR 가구 메쉬 생성
  → Three.js 뷰어 배치
```

## 결과

- 천장고 실측 2.3m → 복원 측정 **2.25m / 2.02m** (오차 0.05~0.28m)
- 겹치는 영역만 많으면 3장으로도 광각 보정된 공간 생성 가능

## 기술 선택

### DUSt3R vs VGGT — 입력 장수별 비교

| | 10장 | 30장 | 100장 |
|---|---|---|---|
| DUSt3R | 우수 | 우수 | CPU 병목 |
| VGGT | 미흡 | 미흡 | 사용 가능 |

- 실제 매물 사진은 3~5장 수준 → 대량 이미지 시나리오가 아님
- 소량 이미지에서 우수한 **DUSt3R 채택** (대량 처리가 필요해지면 VGGT 전환 고려)

### 배경 복원 — 가구를 지우면 빈 공간이 생김

- LaMa 인페인팅: 3D에서 바닥·벽 경계가 안 잡혀 정렬 깨짐
- 단색 벽: 깨끗하게 지워지지만 주변과 이질감
- **주변 Point Cloud 색상으로 가상 벽 생성 → 채택.** 바닥·벽 구분이 자연스러움

## 내 역할 (이종선 · 조장)
