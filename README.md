# 원룸3D — 부동산 사진 기반 3D 공간 재구성

원룸 매물 사진 3~5장만으로 방 구조를 3D로 복원하고, 옵션 가구를 제거한 뒤 사용자의 가구를 배치해볼 수 있는 뷰어를 만든 프로젝트입니다.

ASAC 빅데이터 분석 11기 · 딥러닝 4조 (5인 팀) · 2026.07

## 왜 만들었나

부동산 플랫폼의 매물 사진은 광각으로 촬영돼 실제 공간감이 왜곡되고, 장수도 3~5장으로 한정적입니다. 평면도 기반 인테리어 서비스는 평면도가 없으면 쓸 수 없고, VR 홈투어는 360도 카메라로 재촬영이 필요합니다. 이미 올라와 있는 사진만으로 공간을 복원할 수 있는지 확인해봤습니다.

## 파이프라인

```
사진 3~5장
  → DUSt3R 3D 복원 (Point Cloud)
  → YOLO11s + SAM2 가구 세그멘테이션
  → 주변 Point Cloud 색상 기반 가상 벽 생성 (배경 보완)
  → TripoSR 가구 메쉬 생성
  → Three.js 뷰어 배치
```

## 결과

- 천장고 실측 2.3m 대비 3D 복원 측정값 **2.25m / 2.02m** — 오차 0.05~0.28m
- 겹치는 영역이 많으면 사진 3장만으로도 광각 왜곡을 보정한 공간 생성이 가능함을 확인

## 기술 선택 근거

**DUSt3R vs VGGT** — 입력 이미지 장수별로 비교했습니다.

| | 10장 | 30장 | 100장 |
|---|---|---|---|
| DUSt3R | 우수 | 우수 | CPU 병목 |
| VGGT | 미흡 | 미흡 | 사용 가능 |

실제 매물 사진은 3~5장 수준이라 대량 이미지 시나리오가 아니므로, 소량 이미지에서 우수한 DUSt3R를 채택했습니다.

**배경 복원** — 옵션 가구를 제거하면 빈 공간이 생깁니다. LaMa 인페인팅은 3D 공간에서 바닥과 벽의 경계가 구분되지 않아 정렬이 깨졌고, 단색 벽으로 채우는 방식은 주변과 이질감이 컸습니다. 주변 Point Cloud의 색상 정보로 가상 벽을 생성하는 방식으로 전환했습니다.
